*Rock Paper Scissors Game:*

This is a graphical Rock, Paper, Scissors game built in Java using NetBeans. Play against the computer and track your wins in real time. The project was built to practice Java GUI development using NetBeans and the Swing framework.

*How to Play*

Step 1: Open the application

Step 2: Click Rock, Paper, or Scissors to make your move

Step 3: Then the computer picks randomly on its turn

Step 4: Your choice and the computer's choice are displayed visually

Step 5: The scoreboard updates after each round

Step 6: First to 3 wins gets a prompt to play again

*Features*

~ Graphical interface built with Java Swing 
~ Images displayed for each move (Rock, Paper, Scissors) 
~ Real time scoreboard tracking your wins and the computer's wins 
~ Hover effect on move buttons (border changes colour on mouse enter) 
~ Play again option when someone reaches 3 wins 
~ Computer selection is fully randomised using Java's Random class

*Requirements*

~ Java JDK 8 or higher ~ NetBeans IDE (recommended for opening the project)

*How to Run:*
Open NetBeans
Go to File > Open Project
Select the Rock_Paper_Scissors_Game folder
Click the Run button or press F6
